Workhorse Pro

Every change this extension makes can be turned off on its own.

Features

Keys

Click a binding and press the combination you want. Anything the page can see is fair game — the extension swallows it, so the browser will not act on it while you are in the composer. Leave one empty to unbind it.

GitHub

Naming the checks that failed needs a token. A fine-grained token with read-only Checks access to the repositories you work in is enough — nothing here writes to GitHub. Without one, the check breakdown shows its counts alone.
